# SEAL: Self-Adaptive Energy-Aware Reinforcement Learning for AUV Control

Official source code for **SEAL** (*Self-Adaptive Energy-Aware Reinforcement Learning for Autonomous Underwater Vehicle Control*), submitted to *Advanced Engineering Informatics*.

> **Code-only release:** This repository contains simulation, training, evaluation, and plotting source code. No datasets, trained weights, experiment outputs, logs, or figures are distributed. Trajectories and obstacles are generated by the simulator; training can start without external data.

## About

This project provides a simulation and training framework for **3D autonomous underwater vehicle (AUV) trajectory tracking with spherical obstacle avoidance** under **energy consumption constraints**, targeting marine infrastructure operation and maintenance scenarios.

The proposed method **SEAL** is implemented as **Constrained Soft Actor-Critic (CSAC)** in code — the two names refer to the same algorithm.

## Highlights

- **CMDP formulation** — maximize task reward subject to a discounted energy budget `Jc ≤ θ`
- **Lagrangian Constrained SAC** — twin critics (`Qr`, `Qc`) with adaptive multiplier `λ`
- **Self-adaptive curricula** — progressive tightening of `θ`, plus multi-stage trajectory and ocean-current training
- **Three reference paths** — `circle`, `sinusoid`, `figure8`
- **Baselines included** — SAC (unconstrained) and SAC-E (energy penalty in reward)

## Installation and usage

Use Python 3.10 or newer (smoke-tested with Python 3.12 and PyTorch 2.6).
Run commands from the repository root. A CUDA GPU is recommended for full
training; `--device auto` selects CUDA when available and otherwise CPU.
Install a PyTorch build suitable for your hardware, then install the dependencies.

A quick execution check (not a trained policy):

```bash
python train_csac.py --seed 1 --stages 1 --episodes 1 --frames 32 --device cpu --train-tag smoke
```

Full training, evaluation, and plotting:

```bash
pip install -r requirements.txt

# Train SEAL
python train_csac.py --seed 666 --stages 1,2,3,4 --episodes 2200 --frames 2200000 --device auto

# Evaluate
python evaluate.py --trajectory all --seed 666 --episodes 20 --device auto

# Plot results
python plot_results.py --trajectory all --seed 666
```

Evaluation requires checkpoints produced by training; plotting requires the
corresponding evaluation outputs. Outputs are created locally under
`checkpoints/`, `logs/`, and `figures/` and are ignored by Git.

Baseline training uses `train_sac.py` (SAC) and `train_sacr.py` (SAC-E), with
matching `evaluate_sac.py` / `evaluate_sacr.py` and plotting entry points.
Use `python <script>.py --help` for supported arguments. On Windows,
`run_pipeline.bat` runs the three single-trajectory training stages followed
by evaluation and plotting. Calibration utilities require locally trained
checkpoints and are optional; they are not prerequisites for a fresh run.
Specialized top-three and cross-trajectory analysis scripts also require the
locally generated checkpoints/results indicated by their arguments.

The two local Excel-based energy comparison scripts and archived experiment
copies are excluded from this release. The root `.gitignore` uses an allowlist
to prevent generated files or datasets from being added accidentally.
